# Last Commit · 早睡作息系统

一个帮人从高反馈的电脑工作里慢慢退出来的夜间工具。

它不会催你立刻关机。你先把今晚的时间安排好，把还惦记的事情留给明早，再顺着睡前步骤离开电脑。

## 在线体验

正式体验地址：https://last-commit-sleep.vercel.app

开源仓库：https://github.com/NovaKepler513/last-commit-sleep

当前已经公开，任何人打开链接都能直接进入，不需要 ChatGPT 登录，也不需要安装应用。

这一版已经可以完整使用时间规划、交接清单、睡前步骤和睡眠月历。v12.34.3 共有十二种视频动作：普通点击只抽取真实视频动作，不再把旧的整猫 CSS 动画当成正常回应；视频出现前保持原始站姿，只用一次轻微闪帧完成交接。每段同时准备桌面 WebM 和 iPhone/iPad MOV；如果浏览器丢失透明通道，页面会自动使用静态猫，避免出现灰色方块。

猫话使用“咪”作为第一人称，不使用“我”。气泡不显示标点，需要停顿时只留一个空格。

页面右下角有一只很小的蝴蝶。点开它，可以看到作者署名、开源代码和四套主题猫的使用说明。

## 第一次怎么用

1. 点“进入今晚”，或者按 `Enter`。
2. 在“今晚怎么安排”里选择收工、入睡和起床时间。所有时间以 15 分钟为一档。
3. 调整“想睡多久”。点“按 X 小时重算”时，页面会从起床时间往前推算睡觉时间，再留出一小时收尾。
4. 在“明早先做什么”里写下今天停在哪里，并把明早要做的事逐条加入清单。
5. 点“写好了，开始收工”。睡前步骤会在下面展开。
6. 收好工作资料、做一点别的、洗漱、把手机放远。需要时可以跟着做三轮 4–2–6 呼吸：圆心倒数这一口还剩几秒，右侧正计时显示整段已经做了多久；中途可以暂停、继续或重来。
7. 点“今晚收好”。这晚会出现在睡眠月历里。

第二天早上，交接区会变成“看看昨晚留的事”。任务可以逐项完成；误清空的清单可以恢复。

## 页面里还有什么

- “专注”只保留收工倒计时和像素猫，适合把页面放在旁边看。
- 四种颜色主题会更换页面和空闲猫。视频猫在四套颜色下保持同一只白猫，不随背景偏色。
- 点击、双击或长按猫，会得到不同回应。少数时候它会暂时抓住鼠标，按 `Esc` 可以提前取回。
- “留个备份”可以复制交接内容、导出 Markdown 或生成日历文件。
- “重置今晚”只重置当晚流程。

## 数据与隐私

时间、交接、清单和睡眠记录只保存在当前浏览器的 `localStorage` 中，不会上传到服务器。

这也意味着：

- 换浏览器或换设备后，数据不会自动同步；
- 清理浏览器站点数据可能会删除记录；
- 公开托管者无法看到你的交接内容。

它是一件生活节奏工具，不提供医疗建议，也不替代睡眠障碍的专业诊断。

## 下载后运行

项目没有构建步骤，也没有后端。透明视频需要通过 HTTP 读取首帧；不要双击 HTML 或使用 `file://`，否则浏览器会把视频安全降级成静态猫。

在项目目录启动静态服务器：

```bash
python3 -m http.server 8769 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:8769/
```

根目录的 `index.html` 只是线上与本地静态服务器的入口转接，正式页面仍然使用项目名称命名。

## 部署

这是一个纯静态项目。当前通过 Vercel 托管，项目名为 `last-commit-sleep`，生产地址为 `https://last-commit-sleep.vercel.app`。GitHub 主分支已经连接 Vercel，新提交会触发自动发布。

如果改用 GitHub Pages、Cloudflare Pages 或其他静态托管服务：

1. 把本目录作为公开仓库根目录；
2. 不需要安装依赖，也不需要填写环境变量；
3. 发布目录选择仓库根目录；
4. 确认根网址打开的是 `index.html`；
5. 发布后把真实网址补到本 README 的“在线体验”。

## 当前动作进度

v12.34.3 延续 v12.33 的十二种白猫视频动作。C03、C05、C09、C10、C11、C12 和 C13 使用各自通过审片的原片；C08 复用干净的单爪素材，并在爪子伸出时由网页定帧三秒。普通点击池现在只保留真实视频动作；旧 CSS 动作只在媒体失败或明确的系统状态中兜底。

静态猫在视频首帧完成透明检查前保持原始比例，不再先压扁、横移、翻转或躲藏。进入和退出只保留一次轻微闪帧与等比淡化。iPhone 与 iPad 直接选择 HEVC Alpha MOV，不再因能力判断误选 WebM。猫话同步改为短句，第一人称统一为“咪”，显示层自动删除标点。

C01 仍使用代码动作，因为新片剪短后依然像猫悬空直立。带白色目标方块的 J9506 和中途缩放、残帧明显的 J6772 也没有上线。生成提示词、原片、失败样本和审片材料保存在内部生产档案，不随公开仓库发布。iPhone/iPad 使用 HEVC Alpha MOV，仍需以真实设备画面作为最终透明验收。
